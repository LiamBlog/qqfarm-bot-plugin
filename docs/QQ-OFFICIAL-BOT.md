# QQ 官方机器人接入

3.9.0 新增可选的 QQ 官方机器人提醒和指令入口。默认关闭；未填写机器人凭证、未绑定管理员时，不连接 QQ，不发送消息。

## 接入前准备

在 QQ 开放平台创建机器人，获得 **AppID、AppSecret**，开通所需单聊／群聊事件及消息发送能力。仅在插件管理端填写凭证，不把凭证发送到 QQ 聊天窗口。萌卡访问 Cookie、GitHub PAT 和面板 Token 均不能作为机器人凭证。

管理端 → 设置 → 展开「QQ 官方机器人」。该设置区的代码、数据在展开后加载，账号首页的初始化请求不变。

- **WebSocket**：插件主动建立 WSS 连接，无需对外开放接收端口。订阅 `GROUP_AND_C2C_EVENT (1 << 25)`；支持心跳、断线退避和会话恢复，包括在 RESUMED 前补发的事件。
- **Webhook**：独立监听回调服务，默认 `127.0.0.1:17891`，只处理 `/qqbot/callback`。须自行配置公网 HTTPS、反向代理及必要的容器端口映射。框架登录后才能访问的插件管理页地址不能直接当作公开回调地址。管理 API 仍受原有认证保护。
- **仅提醒**：复用已有绑定，只发送通知，不接收新指令。先通过 WebSocket 或 Webhook 完成绑定。

官方网页仍描述 WebSocket，而官方 Go SDK README 保留旧的链路下线提示。应用是否支持 WSS 必须实际确认；连接失败时可切换 Webhook。本插件不会自动变更服务器反向代理、端口映射或机器人平台权限。

## 配置与绑定

1. 填写 AppID、AppSecret 和接入方式，保存后查看连接状态。「验证已保存的凭证」只校验凭证及所需网关接口，不会发送消息或推送农场账号。
2. 在「添加绑定」中填写名称，选择单聊或群聊，选择允许查询／操作的农场账号及面板。未选择即不授权。推送权限默认关闭。
3. 生成一次性绑定码；由目标管理员在单聊中发送 `/绑定 绑定码`，或在目标群中 @机器人发送同样指令。绑定码 5 分钟过期，仅可使用一次，收起设置会从页面清除。
4. 绑定会记录机器人平台返回的 OpenID。单聊核对用户身份；群聊同时核对群及发送者身份，普通群成员不能继承管理员权限。
5. 需要调整权限时使用「修改授权」；「解除绑定」会撤销此后的查询、推送和接收权限；已提交的任务需在任务中心另行检查，正在执行的远端操作不能撤销。修改 AppID 必须提供新 AppSecret，并清除旧机器人的绑定。
6. 可选择已绑定对象发送测试提醒。测试只发送文字通知，不触发农场推送；平台主动消息权限、接收设置、额度不足时会失败。

不要在群内转发绑定码。有人获得未使用的绑定码，就可能在绑定有效期内认领该范围的权限。

## 指令

| 指令 | 效果 |
| --- | --- |
| `/帮助` | 查看指令说明 |
| `/状态` | 查询授权账号的在线数量 |
| `/账号` | 查看授权账号与面板的 A/P 序号；账号号码脱敏 |
| `/推送 A1 P1` | 把授权账号推送到授权面板 |
| `/推送 A1` | 按现有账号路由推送；路由含未授权面板时整次阻止，不会偷偷改投 |
| `/任务 任务编号` | 查询权限范围内的任务进度 |
| `/重试 任务编号 确认` | 在用户明确确认后重试失败／中断任务；应先核实远端状态 |
| `/通知 开`、`/通知 关` | 修改当前绑定的提醒开关 |

也可使用 `/农场 状态` 等前缀形式。群聊需 @机器人。A/P 序号来自绑定权限的顺序，某账号暂时消失不会让其序号指向另一个账号；修改授权范围后请重新查询 `/账号`。

推送仍通过萌卡原生 IPC 获取农场 Code，并进入已有任务队列、路由、并发与重试流程。QQ 官方机器人不替代普通 QQ 账号登录，也不负责获取农场 Code。推送可能重启面板中正在运行的会话，请谨慎操作。

## 提醒、限流与数据保护

可按绑定接收推送成功／失败、账号离线、面板故障／恢复通知。账号和面板权限同时约束相关通知；同一目标的重复告警会冷却合并。直接触发的任务优先通过原消息回复反馈，回复窗口或次数耗尽后，仅在该绑定开启主动提醒时尝试主动通知。

- 事件先持久化去重，再触发操作；无法写入去重记录时阻止执行。收到重复事件不会重复排队。
- 单聊回复采用保守的 5 分钟窗口（官方页面概述与字段说明存在差异），最多 4 次；群聊最多 5 次。任务结果使用递增的 `msg_seq`。
- 全局发信间隔至少 3.1 秒，队列有上限。平台仍可施加更严格的权限、频率、额度和接收方限制，以实际返回为准。
- 网络超时、平台拒绝或结果不确定时不自动重发 QQ 消息；可在管理端查看最近的发送结果。
- 不发送农场 Code、面板密码、Token 或访问凭据；通知只含状态、脱敏标识与任务编号。任务详细错误留在管理端。
- 接收方关闭主动消息时关闭相关绑定的主动提醒；删除好友／移除机器人时撤销相关绑定。
- Webhook 使用 AppSecret 派生 Ed25519 密钥，验证原始请求体与时间戳签名；拒绝过期、未签名、超大请求。
- `qqbot.json` 保存凭证及绑定，`qqbot-events.json` 保存事件去重记录，均位于框架分配的数据目录并按私密文件写入。它们不包含在原有配置导出中。AccessToken 只在服务端内存缓存，不回传页面。

未配置真实 QQ 机器人应用时，只能完成本地协议模拟和页面测试，不能称为真实 QQ 发送成功。
